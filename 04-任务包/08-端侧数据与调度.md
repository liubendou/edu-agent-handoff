# 08 · 端侧数据与调度

> 归属模块：`:core:data`（包 `com.eduagent.core.data.<layer>`）。
> 契约依据：`01-契约.md` §10（8 表 + DataStore 8 键 + 画像硬触发器）、§11、§12、§13（D4/D11/D18/D31/D32）、§14。
> 本步让端侧能**本地**算出「今天该学什么」，断网也要能算（验收 K1.5）。

---

## 0 本步目标

在 `:core:data` 落成 端侧数据与调度全量：

| 子目标 | 契约条款 | 交付后可观测结果 |
|---|---|---|
| Room 落库 | §10 | `eduagent.db` v1，**8 张表**；每次 schema 变更**必须写 Migration 并加迁移测试** |
| DataStore 键 | §10 | 8 个 Preferences 键，取值逐字一致 |
| 仓库层 | §10 | Knowledge / Review / Profile / Session / Metric 五类仓库 |
| 复习算法 | D4 | 冷启动 **SM-2**；单 item 历史 **≥ 20 次复习**后转 **FSRS** |
| 今日调度 | D31 | 逾期 `1.0` > 薄弱 `0.7` > 新学 `0.5`；同组内 `due_at` **升序**；权重常量化于 `:core:data` |
| 画像仓库 | §10 | 硬触发器产出条目；`sensitivity=HIGH` **本地隔离、不上云** |
| 离线兜底 | K1.6 | 无网可复习、结果可回写、恢复网络不丢 |

`minSdk 29`（D11）为冻结值，不得改。

## 4 完成判据

### 4.1 机检

命令：`./gradlew :core:data:test`（须全绿，输出测试数）。必须包含：

| 测试 | 断言 |
|---|---|
| Room in-memory | 8 张表可建、可读写；schema v1 导出成功 |
| SM-2 行为 | 对同一 item：**答对延长档期、答错缩短档期**（C1.5） |
| FSRS 切换 | 单 item 历史 `< 20` 次走 SM-2；`≥ 20` 次后 `algo=FSRS`（D4） |
| 迁移测试 | 任意 schema 变更均有 Migration 且迁移测试通过 |
| 调度排序 | 逾期 `1.0` > 薄弱 `0.7` > 新学 `0.5`；同组内 `due_at` 升序（D31） |
| 画像入库 | 硬触发器产出条目；**用户拒绝的条目不入库**（R-E5）；删除后彻底不可恢复（R-D2） |
| 敏感隔离 | `sensitivity=HIGH` 条目不进入任何上行路径（R-D1） |
| 离线回写 | 无网状态下复习结果可回写；恢复网络后不丢（K1.6） |

### 4.2 人工检查点（非程序员可执行）

| # | 你做什么 | 看到什么算通过 | 不通过退回本步哪一项 |
|---|---|---|---|
| 1 | **断开网络**打开 App，进入复习入口 | 今日复习内容**仍算得出**（本地计算，无转圈） | §0 离线兜底（K1.5） |
| 2 | 完成一次复习 → 杀进程 → 重进 App | 掌握度与档期**被保留**，下次到期时间按算法重算 | §0 复习算法（C1.4） |
| 3 | 上传成绩单，触发画像写入 | 出现「我记住了这些」卡；**可改可删**；删掉的条目不出现 | §0 画像仓库（C3.2） |
| 4 | 打开画像页，删除一条敏感画像 | 删除后下回合不再被引用，本地不可恢复 | §5 R-D2 / P3.2 |
| 5 | 隔天再打开 App | 队列、画像、历史均**连续**，无丢失 | §0 落库与仓库（P2.2） |

## 5 本步红线

| ID | 红线（逐字） | 本步拦截手段 |
|---|---|---|
| R-D1 | 成绩、错题、情绪敏感点默认不上云；v1 冻结为全部本地 | `sensitivity=HIGH` 条目本地隔离，不进任何上行路径 |
| R-D2 | 用户删除画像必须彻底删除（本地+云端），不可软删除 | 删除走物理删除 + 删除测试 |
| R-D3 | 用户数据不得用于训练模型、不得共享第三方 | 无外发通道；`content_scope` 只存首版范围 |
| R-D4 | 日志中不得出现成绩、姓名、情绪内容明文 | 仓库日志脱敏；埋点只写 `metric.name/value` |
| R-E4 | 画像不得推断心理疾病、家庭状况、经济条件 | 只抽取学习相关显性事实 |
| R-E5 | 任何画像写入必须先给用户可见确认；拒绝的条目不得入库 | 落库前渲染 `profile_confirm_card`，拒绝项丢弃 |
| R-E6 | 敏感条目不得用于展示、分享、排行榜 | `sensitivity=HIGH` 不进入任何展示查询 |
| D4/D31 | 算法与权重冻结 | SM-2→FSRS@20；权重 `1.0/0.7/0.5` 常量化 |
| D11 | `minSdk 29` | 冻结，不得改 |
| D18 | 画像段上限 ≤ 800 token | 裁剪按「影响当前回合决策程度」 |

## 6 禁止事项

1. 禁止 schema 变更不写 Migration、不加迁移测试（§10）。
2. 禁止 `sensitivity=HIGH` 条目进入任何上行/展示/日志路径（R-D1/R-E6/R-D4）。
3. 禁止软删除画像（R-D2）。
4. 禁止未经 `profile_confirm_card` 确认直接落库画像（R-E5）。
5. 禁止在日志/埋点写成绩、姓名、情绪明文（R-D4）。
6. 禁止把队列权重写死为魔数而不集中到 `ReviewWeights`（D31）。
7. 禁止在 SM-2/FSRS 之外自造算法或改变 20 次切换阈值（D4）。
8. 禁止 `:core:data` 依赖 `:core:design`/`:ui:parts`/`feature`（§2 方向铁律）。
9. 禁止硬编码中文文案（§14.2）；禁止在仓库层直连网络（本步离线优先）。
10. 禁止改动 `assets/contract/*.json` 的 schema（§0 全局纪律）。

## 7 交给下一步的接口

**7.1 Room 表（`:core:data`，`eduagent.db` v1；列名与契约 §10 逐字一致）**

| 表 | 列 |
|---|---|
| `knowledge_item` | `id`(PK) `subject` `stage` `title` `content_hash` `created_at` `leech` |
| `review_state` | `item_id`(PK/FK) `algo` `stability` `difficulty` `due_at` `reps` `lapses` `last_grade` |
| `review_log` | `id`(PK) `item_id` `grade` `elapsed_ms` `at` `session_id` |
| `profile_entry` | `id`(PK) `category` `key` `value` `sensitivity` `scope` `confirmed_at` `source` |
| `session` | `id`(PK) `mode` `started_at` `ended_at` `token_in` `token_out` `model_used` `downgrade_level` |
| `message` | `id`(PK) `session_id` `role` `content_ref` `seq` |
| `part_render` | `id`(PK) `message_id` `type` `catalog_version` `payload_json` |
| `metric` | `id`(PK) `name` `value` `at` |

**7.2 DataStore 键与取值（§10 逐字）**

| 键 | 取值 |
|---|---|
| `model_pref` | `FLASH`(默认) / `PRO` |
| `motion_level` | `full` / `reduced` / `minimal`（系统移除动画时**只读**） |
| `motion_user_override` | 用户显式选择，系统 minimal 时被忽略 |
| `haptics_enabled` | 默认 `true` |
| `first_run_done` | 布尔 |
| `boost_horizon` | `SHORT` / `LONG` |
| `theme` | `light` / `dark` / `system` |
| `content_scope` | 首版 `高中·数学,英语` |

**7.3 第 9 步依赖的端口（Kotlin 签名）**

| 类型 | 签名 | 供第 9 步用法 |
|---|---|---|
| `enum class QueueGroup` | `OVERDUE, WEAK, NEW` | 权重 `1.0 / 0.7 / 0.5` |
| `object ReviewWeights` | `const val OVERDUE = 1.0f`；`WEAK = 0.7f`；`NEW = 0.5f` | D31 |
| `enum class Algo` | `SM2, FSRS` | 落 `review_state.algo` |
| `enum class Sensitivity` | `LOW, HIGH` | 落 `profile_entry.sensitivity` |
| `enum class ProfileScope` | `STABLE, RECENT` | 落 `profile_entry.scope` |
| `data class TodayItem` | `(itemId: String, priority: Float, group: QueueGroup, dueAt: Long)` | 队列项 |
| `data class TodayPlan` | `(generatedAt: Long, items: List<TodayItem>)` | 「今天学什么」结果 |
| `interface Scheduler` | `fun todayPlan(nowMillis: Long): TodayPlan` | **第 9 步 `TASK` 段**注入端侧调度结果 |
| `interface ReviewRepository` | `suspend fun dueItems(nowMillis: Long): List<KnowledgeItem>`；`suspend fun submitReview(itemId: String, grade: Int, elapsedMs: Long, sessionId: String): ReviewState` | 复习读写 |
| `interface ProfileRepository` | `fun forContext(scope: ProfileScope): List<ProfileEntry>`（**只返回 `sensitivity=LOW`**）；`suspend fun commitConfirmed(entries: List<ProfileEntry>)`（拒收条目不入库）；`suspend fun deleteAll()` | 第 9 步 `PROFILE` 段只用 LOW；上限 ≤ 800 token（D18） |

**7.4 第 10 步集成入口**

- 回写链路：复习判分 → `review_log` → 重算 `review_state`（SM-2/FSRS）→ 更新 `Scheduler` 队列。
- 流式产出：第 7 步 `StreamUnit.type` → `part_render.type`；`payload` → `part_render.payload_json`；`catalog_version` 由第 9 步写入。
- 兜底级别：三级兜底链结果 → `session.downgrade_level`。
- `grade: Int` 为 SM-2 质量分（0~5）；答对=高分、答错=低分的具体映射由第 10 步定，本步只存原值。
