# 07 · 流式引擎与状态纪律

> 归属模块：`:core:domain`（包 `com.eduagent.core.domain.stream`）。
> 契约依据：`01-契约.md` §8.5（双层平滑 / 五档 tau / rAF 五铁律 / 状态纪律 / 中断竞态）、§7、§11、§12、§13、§14。
> 云侧真实 SSE 归第 9 步；本步用 `FakeTokenSource` 自证，**不接真模型**。

---

## 0 本步目标

在 `:core:domain` 的 `stream` 包实现纯 Kotlin 流式内核，覆盖契约 §8.5 全部条款：

| 子目标 | 契约条款 | 交付后可观测结果 |
|---|---|---|
| 粗平滑 | §8.5 | 按 16ms 帧窗口聚合后再下发；**首帧立即下发**；**结束前必须 flush**（不丢尾） |
| 细平滑 | §8.5 | 按「行/零件」匀速消费，`rate = clamp(backlog / tau, MIN, MAX)`，积压加速、追平减速 |
| Compose 版 rAF 五铁律 | §8.5 | 见 §5 表，逐条可测（`withFrameNanos` 循环） |
| 相位机 | §7/§8.5 | `WAITING → THINKING → BODY`；等待 **> 8s 必须显式提示** |
| 中断与竞态 | §8.5 | 停止按钮 ≤100ms 变「正在停止…」并禁用；生成中拦截会话切换/退出必须可见提示，禁止静默 |
| 状态纪律 | §8.5/§14.3 | 流式正文与思考流走**局部 state**，绝不进全局；思考流**不回传**下一轮 |

**本步必须同时产出**：`FakeTokenSource`（本地模拟 token 流，供本步演示与测试，不依赖第 9 步网络层）与 `StreamDemoScreen`（debug 演示页），否则本步无法人工检查。

本步只做内核与 debug 演示，**不做**视觉体系、不做零件入场（零件入场归第 6 步）。

## 4 完成判据

### 4.1 机检

命令：`./gradlew :core:domain:test`（须全绿，且输出测试数）。必须包含：

| 测试 | 断言 |
|---|---|
| 粗平滑 | 首帧立即下发；16ms 窗口聚合；**结束前 flush，无丢尾** |
| 五铁律·收敛 | 结束条件可收敛：积压吐完 → `Ended(NORMAL)`，无恒真循环 |
| 五铁律·重入 | 重入只查 `frameJob` 句柄，不被兜底定时器阻塞 |
| 五铁律·钳制 | 喂 5s 时间增量，单帧推进仍被钳制到 **0.1s** 上限（不一次性喷完积压） |
| 五铁律·后台 | 后台兜底按真实流逝时间推进，且**补发结束回调** |
| 五铁律·abort | `abort`/错误立即 `Ended(ABORTED/ERROR)`，不等匀速吐完 |
| 相位机 | `WAITING → THINKING → BODY` 顺序正确；等待 **> 8000ms** 发 `SlowNotice` |
| 中断竞态 | `requestStop()` 后 **≤100ms** 发 `Stop(STOPPING_DISABLED)` 并禁用 |
| **收尾压测（V3）** | **连续 100 次流式收尾**：每次必有 `Ended`；无「回答完了还在转」、无丢尾、无卡死 |
| 状态纪律 | 断言内核无全局可变状态；思考流不回传（不累积进 HISTORY） |

### 4.2 人工检查点（非程序员可执行）

| # | 你做什么 | 看到什么算通过 | 不通过退回本步哪一项 |
|---|---|---|---|
| 1 | 装 debug 包，打开「流式演示页」，跑一次流式 | 字**匀速**出现，无跳字、无整块蹦出、无「回答完了还在转」 | §3 内核 · 五铁律·收敛 |
| 2 | 同一屏点「停止生成」 | 按钮**立即**（≤100ms）变「正在停止…」并禁用，随后有终态 | §0 中断与竞态（V4） |
| 3 | 让假流源首片延迟 > 8 秒 | 8 秒内出现显式「模型正在思考」提示 | §0 相位机（V6） |
| 4 | 生成中点会话切换/退出 | 出现**可见**提示，不是什么都不发生 | §0 中断与竞态 |
| 5 | 连续跑 3 次流式 | 每次结尾都正常收尾，无悬挂 | §4.1 收尾压测（V3） |

## 5 本步红线

| ID | 红线（逐字） | 本步拦截手段 |
|---|---|---|
| R-P3 | 不得出现空白回合、静默失败、无解释的转圈 | 相位机必有终态；中断/退出必须可见提示；等待 >8s 必提示 |
| R-P7 | 动效不得阻塞交互可用性 | 「停止生成」≤100ms 反馈并禁用（V4）；M2 约束 |
| R-T2 | 断点前三段逐字节稳定 | 思考流**不回传**下一轮，不污染 `HISTORY`（§8.5） |
| M5 | 流式渲染不得因动效掉帧：帧率 < 45fps 优先砍动效，不砍流式 | 细平滑独立于动效层，帧率下降只降动效 |
| V3 | 连续 100 次流式收尾可靠 | §4.1 收尾压测 |
| V4 | 停止生成即时反馈 ≤100ms | §4.1 中断竞态单测 |
| V6 | 等待超 8 秒有提示 | §4.1 相位机单测 |
| K1.8 | 零件在弱网/流式下可读 | 流式过程无错位、跳版 |

> §8.5 的五条铁律与状态纪律虽无独立红线 ID，但属**契约级不可协商项**，违反即按 R-P3 / M5 同类处理。

## 6 禁止事项

1. 禁止把流式正文/思考流写进 ViewModel 全局状态或列表（§8.5 状态纪律）。
2. 禁止恒真结束条件；禁止用长期兜底定时器阻塞重入判断（铁律 1/2）。
3. 禁止不钳制帧时间增量（上限 **0.1s**，铁律 3）。
4. 禁止后台兜底路径不补发结束回调（铁律 4）。
5. 禁止 `abort`/错误后仍走「吐完再收尾」（铁律 5）。
6. 禁止静默拦截会话切换/退出（红线 R-P3 同类）。
7. 禁止在本步预写第 9 步网络层；禁止在 feature 层直接建 HTTP 客户端（§14.6）。
8. 禁止在 `:core:domain` 依赖 `:core:design`、`:ui:parts` 或 `feature`（§2 方向铁律）。
9. 禁止硬编码中文文案（§14.2）；页面禁止裸 `tween(300)` 参数（§14.4）。
10. 禁止改动 `assets/contract/*.json` 的 schema（§0 全局纪律）。

## 7 交给下一步的接口

**7.1 本步冻结公开 API（`:core:domain`，包 `com.eduagent.core.domain.stream`）**

| 类型 | 签名 / 取值 | 说明 |
|---|---|---|
| `enum class StreamPhase` | `WAITING, THINKING, BODY` | 相位机（等待/思考/正文） |
| `enum class EndReason` | `NORMAL, ABORTED, ERROR` | 积压吐完 / abort / 错误 |
| `enum class StopState` | `IDLE, STOPPING_DISABLED` | 停止按钮态 |
| `data class TokenChunk` | `(val text: String, val isThinking: Boolean = false)` | 云 token 原始片 |
| `interface TokenSource` | `fun chunks(): Flow<TokenChunk>` | **第 9 步必须实现**（DeepSeek SSE 适配） |
| `data class StreamUnit` | `(val seq: Int, val raw: String, val envelope: PartEnvelope?)` | 细平滑吐出的「行/零件」；`envelope == null` = 纯文本行 |
| `sealed interface StreamEvent` | `Delta(text)` / `Thinking(text)` / `Unit(unit)` / `Phase(phase)` / `SlowNotice(waitedMillis)` / `Stop(state)` / `Ended(reason)` / `Failed(message)` | 消费侧唯一事件源 |
| `class StreamKernel` | `fun stream(source: TokenSource, mode: Mode, tau: Float): Flow<StreamEvent>`；`fun requestStop()`；`fun abort()` | 内核入口 |

**7.2 常量与枚举（逐字来源）**

| 项 | 值 | 来源 |
|---|---|---|
| 帧窗口 | `FRAME_WINDOW_MILLIS = 16L` | §8.5 |
| 时间增量钳制上限 | `DT_CLAMP_SECONDS = 0.1f` | §8.5 铁律 3 |
| 等待提示阈值 | `SLOW_NOTICE_MILLIS = 8000L` | §8.5（V6） |
| 停止反馈上限 | `STOP_FEEDBACK_MILLIS = 100L` | V4 |
| 五档 tau | `quick=0.18f / standard=0.25f / deep=0.35f / review=0.15f / boost=0.30f` | §8.5、D29、第 5 步 `StreamTau`（同值） |
| `Mode` | `QUICK, STANDARD, DEEP, REVIEW, BOOST`（定义于 `com.eduagent.core.model.Mode`） | ↔ 契约 §5 小写 mode：`quick/standard/deep/review/boost` |
| `PartEnvelope` | `{ v:Int=1, id:String, type:String, payload:JsonObject }`（定义于 `:core:model`） | §4、第 6 步 §7 |

**7.3 第 8 步最小依赖（`:core:data`）**

- `StreamUnit.envelope.type` → `part_render.type`；`envelope.payload` → `part_render.payload_json`；`catalog_version` 由第 9 步装配时写入。
- 回合结束态 `EndReason` 决定 `message` / `session.ended_at` 的回写时机；兜底级别落 `session.downgrade_level`（值由第 9 步三级兜底链给出）。

**7.4 第 9 步必须实现**

- 实现 `TokenSource`：把 OkHttp SSE 逐行适配为 `Flow<TokenChunk>`，思考片 `isThinking = true`。
- 调用 `StreamKernel.stream(source, mode, tau)`；`StreamEvent.Failed(message)` 交由三级兜底链消费（§7）。
- `tau` 取自 `com.eduagent.core.design.motion.StreamTau`（按 `mode` 逐档取值），在装配层注入。

**7.5 第 10 步集成入口**

- UI 只消费 `StreamEvent`：正文/思考流写**局部 state**（`remember { mutableStateOf }`），全局仅存 `StreamPhase`、请求 ID、重试提示；`StreamUnit.envelope` 交给 `PartHost(envelope)` 渲染。
- 路由 `StreamDemo` 由第 10 步在 `:app` 导航图挂载（与 `MotionGallery`/`PartGallery` 同级）。
