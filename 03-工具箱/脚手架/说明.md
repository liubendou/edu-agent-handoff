# 03-工具箱 · 脚手架说明

本目录是**只读工具箱**。第 2 步施工时从这里取用，不要修改本目录内容。

## 1. 脚手架（Google 官方）

| 目录 | 说明 | 在本项目怎么用 |
|---|---|---|
| `android-architecture-templates\` | Google 官方单模块架构模板（Compose + Room + Hilt + KSP + 版本目录 + CI 草案） | **备用**：做对照参考，看官方目录/约定怎么写 |
| `android-architecture-templates-multimodule\` | Google 官方**多模块**模板（`core:*` / `feature:*` 分模块 + 约定插件 `build-logic`） | **第 2 步的起点**：以它为骨架，改成契约 §2 的 8 个模块 |

来源：`android/architecture-templates`（github），已连同官方 `build-logic` 与版本目录一起拉取到本地。

**使用方式**：第 2 步把 multimodule 模板的 `settings.gradle.kts` / `build-logic/` / `gradle/` 结构复制进 `d:\agent\edu-agent-kt`，然后：
1. 模块清单按契约 §2 改写（8 个模块、依赖方向单向、core 不得依赖 feature）。
2. 版本一律以本目录的 `libs.versions.toml` 为准，**覆盖模板里的任何版本号**。
3. `minSdk 29 / compileSdk 36 / targetSdk 36`（契约 §13 D11）。

## 4. 版本目录

`libs.versions.toml` = **冻结版**，含三类必选库：
- UI 库：`material3`（BOM 管）+ `material3-adaptive 1.3.0` + `vico compose-m3 3.3.1`
- 微动作库：`compose-shimmer 1.5.0` + Compose 触觉 API（框架内置，无需依赖）
- 动画库：`compose-animation`（BOM 管）+ `constraintlayout-compose 1.1.2`（MotionLayout）+ `lottie-compose 6.6.6`（选装）

核验时间 2026-10-18，来源 Google Maven / Maven Central。**不得**擅改版本号；确需新增依赖 → 登记本文件 + 在 `00-总纲.md` §二 表格补一行。
