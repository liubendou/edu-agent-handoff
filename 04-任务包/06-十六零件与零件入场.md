## 6 禁止事项

1. 禁止在零件 payload 里塞任何动效/时长/曲线字段（R-T10）。
2. 禁止零件自带入场/退出动画参数——入场统一走 `PartEntrance`，动效统一走 `:core:design`（§14.4）。
3. 禁止在零件内使用「缩放弹出」入场（§8.5 明文禁止）；只需要透明度 + 上移 8~12px。
4. 禁止对已入场零件重排；新零件必须插下方，容器只向上补位。
5. 禁止把 `answer` 在判分前下发给 UI（§4 硬规则）；`quiz_card`/`verdict_card` 必须成对出现。
6. 禁止渲染无 `source` 的 `tool_card` 结果项（R-C1/R-C2）。
7. 禁止对判废零件位使用红色报错框（§7 二级兜底视觉 → 纯文本段落）。
8. 禁止未知 type 崩溃或白屏；必须走 `unknown_part` 埋点并降级渲染（§7 降级纯文本）。
9. 禁止在本步实现实际业务页面、会话流或云侧装配（那是第 7 / 9 / 10 步）。
10. 禁止 `:ui:parts` 依赖 `:feature:*` 或反向被 `:core:design` 依赖（§2）。

## 7 交给下一步的接口

第 7 步（流式内核）、第 9 步（validator/兜底）、第 10 步（集成）依赖以下**确切路径与 API**：

**A. 16 个 `type` 名（逐字取自 §4，注册表键）**

```
explain_card | keypoint_card | compare_card | quiz_card | verdict_card |
error_cause_card | map_card | timeline_card | table_card | plan_panel |
progress_card | review_card | diagnose_card | profile_confirm_card |
material_card | tool_card
```

**B. 注册表 API（第 9 步 validator 与第 10 步渲染调用）**

| API | 定义位置 | 说明 |
|---|---|---|
| `com.eduagent.parts.PartRegistry.types` | `PartRegistry.kt` | `List<String>`，上表 16 个，顺序同 §4 |
| `PartRegistry.composableFor(type: String)` | 同上 | 返回 `@Composable (PartEnvelope) -> Unit`；未知 type 返回降级渲染器 |
| `@Composable PartGalleryScreen(onBack: () -> Unit)` | `gallery/PartGalleryScreen.kt` | 陈列页；仅 debug 由 `:app` 挂载 |
| 渲染入口 | `@Composable fun PartHost(envelope: PartEnvelope, modifier: Modifier = Modifier)` | :app / :feature:main 只调它，不直接调具体零件 |

**C. 零件函数签名（统一形态，第 7 步按行到达即调用）**

```kotlin
// 每个零件：@Composable fun XxxPart(payload: XxxPayload, modifier: Modifier = Modifier)
@Composable fun ExplainCardPart(payload: ExplainCardPayload, modifier: Modifier = Modifier)
@Composable fun QuizCardPart(payload: QuizCardPayload, modifier: Modifier = Modifier)

@Composable fun ToolCardPart(payload: ToolCardPayload, modifier: Modifier = Modifier)
// …其余 12 个零件同此形态；payload 类型由 :core:model 定义
```

**D. 入场 / 流式 / 兜底（第 7 步直接复用）**

| API | 签名 | 依据 |
|---|---|---|
| `Modifier.partEntrance()` | `fun Modifier.partEntrance(level: MotionLevel = LocalMotionLevel.current): Modifier` | §8.5-①②（透明度 + 上移 8~12px、`base`） |
