## 4 完成判据

### 4.1 机检

```powershell
cd d:\agent\edu-agent-kt
.\gradlew contractCheck          # 必须 BUILD SUCCESSFUL
```

`contractCheck` 必须逐项断言（缺一项即视为未完成）：

1. `parts.json` 条数 = **16**，`type` 集合与契约 §4 表**逐字**一致（大小写、下划线）；每条 `payload_required` 非空。
2. `signature-matrix.json` 5 档齐全；每档 `required` 里的每个签名都能在 `parts.json` 的 `type` 集合中找到（否则是坏引用）；`boost` 档 `required_any_of` 长度 = 2。
3. `context-segments.json` 顺序严格等于 `SYSTEM → PSY_INDEX → CATALOG → SKILL → PROFILE → TASK → HISTORY → RETRIEVAL`，`breakpoint_after = 3`，且前 3 段的 `is_prefix = true`。
4. `redlines.json`：ID 无重复、无空缺；必须含 `R-P7`、`R-T10`、`D9`；每条 `enforcement` ∈ {machine, human}。
5. `acceptance.json`：ID 无重复；`level` ∈ {P0,P1,P2}；必须含 `V1`~`V8`、`S1.8`、`K1.5`、`X1.1`、`P3.1`。
6. `decisions.json`：D1~D33 连续无缺口；每条有 `landing_step`（1~10）。
7. `motion-tokens.json`：`micro=120 / base=200 / slow=600 / draw=800`；`snappy=(380,30) / default=(260,30) / soft=(260,26)`；`tau=(0.18,0.25,0.35,0.15,0.30)` **数值逐字一致**；`recipes` 长度 = 10，每条含 `minimal_fallback`。
8. `libs.versions.toml`：三类库 6 个坐标齐全 —— `material3-adaptive 1.3.0`、`vico compose-m3 3.3.1`、`compose-shimmer 1.5.0`、`constraintlayout-compose 1.1.2`、`lottie-compose 6.6.6`、`compose-animation`（BOM 管）。
9. **反向用例必须能失败**：`ContractCheckNegativeTest` 证明「删掉一个零件 type 后校验报错」——否则校验器等于空跑。
