## 2. 严禁使用的

- 前版的 **Lynx / ReactLynx / TypeScript** 代码、组件、状态管理实现
- 前版的 `src/a2ui`、`src/components`、`src/pages`、`src/orchestrator` 等**实现代码**（本项目一律用 Kotlin/Compose 重写）
- 前版依赖（`@lynx-js/*`、rspeedy 等）

**判断标准**：能搬的是「内容与参数」（技能话术、动效数值、心理学条目素材、验收清单），不能搬的是「代码与技术栈」。任何产出里出现 `Lynx`、`.tsx`、`lynx.config` 字样即视为本步不合格。

## 3. 为什么要重写

原文档写死 Lynx 4.0，但本产品第一版只做 Android：跨端收益为 0，却要背 JS 运行时 + 桥接开销 + 卡帧风险（动效红线 M5 要求流式期间 ≥45fps）。改用 Kotlin + Jetpack Compose 后：
- 动效文档的弹簧参数（380/30、260/30、260/26）**正好是** Compose `Spring(stiffness, dampingRatio)` 的原生参数，1:1 直译，不需要 cubic-bezier 近似；
- 系统「移除动画 → 强制 minimal」可直接读 `LocalMotionDurationScale`，不需要文档里那条「待确认 Lynx 读取方式」；
- 「流式正文走局部订阅状态、绝不进全局」由 Compose snapshot 状态的按读取点重组天然满足。

详见 `01-契约.md` §1/§8 与 `00-总纲.md` §二。
